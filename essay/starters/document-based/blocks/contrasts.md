# Contrasts

A flat list, one entry per question two or more documents speak to. Each entry names the question,
says by label which documents agree, which conflict and which are silent, and ends in a ruling:
the document that wins and the rule that picked it. This is where the essay's argument is actually
decided; the thesis states what the rulings add up to.

Rulings that recur: a primary record beats a later account, a direct count beats a description, a
witness beats a bystander, and a document that restates another counts once. A document silent
where its author should have spoken — a memo about the line that never mentions who is in it — is
evidence too; record it.

> **Who waits at peak hours** — single-book patrons [Doc A], against "nearly half the evening line
> is seniors who want help finding a hold" [Doc C]. Ruling: Doc C — a count of the line beats a
> funding request's description of it.
