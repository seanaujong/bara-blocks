# Documents Consulted

One entry per document, each with a stable label, its sourcing, and its claims quoted — so the
essay's later rulings can say why one document outweighs another. Use the label the prompt gives a
document (Doc A, Document 3); give it a short one if the prompt doesn't.

The sourcing is the history classroom's HIPP: the **historical** context it was written in, its
intended **audience**, its **purpose**, and its author's **point of view**. Each part only counts
when it says how it changes the claim's weight — a memo written to win funding has a reason to make
the problem sound simple.

> **Doc A** — Branch manager's memo, 2024, to the library board, asking for kiosk funding: "Peak-hour
> lines are mostly patrons returning or renewing a single book." Written to win a budget vote, so it
> has reason to describe the line as the kind kiosks fix.
