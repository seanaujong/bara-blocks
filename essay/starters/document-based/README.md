# Document-Based Essay

> Argues a thesis built from a set of source documents, the way an AP history DBQ does: the
> documents are weighed against each other before the thesis is written, and the thesis rests on
> the rulings between them rather than on any one source.

## Blocks

### [Documents Consulted](./blocks/documents-consulted.md)

> **Doc A** — Branch manager's memo, 2024, to the library board, asking for kiosk funding: "Peak-hour
> lines are mostly patrons returning or renewing a single book."

### [Contrasts](./blocks/contrasts.md)

> **Who waits at peak hours** — single-book patrons [Doc A], against "nearly half the evening line
> is seniors who want help finding a hold" [Doc C]. Ruling: Doc C — a count of the line beats a
> funding request's description of it.

### [Thesis Statement](../../blocks/opening/thesis-statement.md)

**For this starter:** answers the prompt with a position the documents can support, and settles at
least one contrast in the course of making it.

> "Self-checkout shortened the library's lines, but the patrons it served were not the ones waiting
> longest [Doc A][Doc C]."

### [Evidence](../../blocks/body/evidence.md)

**For this starter:** each body point cites the contrast or document it rests on, and adds at least
one piece of evidence from outside the documents — the AP rubric scores that separately. A point
that cites nothing is an assumption; say so or cut it.

> "Evening hold pickups rose 30% the year the branch moved holds to self-service shelves (outside
> evidence: county library statistics), which is why the seniors in Doc C's count were waiting."

### [Conclusion](../../blocks/closing/conclusion.md)

> "The kiosks solved the problem the memo described, which was not quite the problem the line had."

## Pitfalls

- Summarizing each document in turn — "Doc A says…, Doc B says…" — instead of setting them against
  each other.
- Sourcing that only restates the author's name, with no word on why their purpose or audience
  changes how far to trust the claim.
- Ignoring the document that disagrees with the thesis; the strongest essays rule on it openly.
