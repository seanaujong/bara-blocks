# Boundary

A box drawn around a group of elements to mark "everything in here is the thing this diagram is
about" — the software system's boundary in a Context or Container diagram, or a container's
boundary in a Component diagram. Everything outside the boundary is a supporting element: shown
because something inside talks to it, but not decomposed further at this zoom level.

> The "Library Self-Checkout System" boundary, in a Container diagram, contains the Kiosk App,
> the Checkout API, and the Catalog Database — but not the external Payment Processor.
