# Elements

> **At a glance.** An element is the smallest thing you draw a box or arrow for — a person, a
> system, a container, a component, a relationship between them. These are the elements used by
> more than one diagram type; an element used by only one type lives with that type instead, at
> `types/<type>/components/`.
>
> **Naming note.** This folder is called `components/` for consistency with the rest of this repo
> (see [`essay/components/`](../../../essay/components/README.md)) — "component" here just means
> "building block." The [C4 model](https://c4model.com/) separately uses the capitalized word
> **Component** for one specific element (a grouping of code behind an interface) and one specific
> diagram type (zoomed into a single container). The two uses of the word are unrelated; when this
> repo means the C4-specific one, it says "Component" with a link.
