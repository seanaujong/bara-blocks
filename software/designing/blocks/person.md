# Person

A human (or role) who uses a system — a user, actor, or persona. Drawn the same way at every
zoom level; it never gets decomposed the way a system does.

Used in Context, Container, and Component diagrams wherever a human touches the system being
drawn.

> "Patron" — checks a book out without a staffed register.
> "Librarian" — resolves exceptions the machine can't handle.
