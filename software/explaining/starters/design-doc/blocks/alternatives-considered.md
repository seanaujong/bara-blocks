# Alternatives Considered

Other real options that were weighed before the proposed one, each with its actual tradeoff — not
strawmen included only to be dismissed. Its absence is what makes a design doc read as "I already
decided" rather than "here's how I got here," and it's what gives a reviewer something concrete to
push back on.

> "Keep the staffed register and add a second one at peak hours — cheaper to build, but doesn't
> reduce headcount and still bottlenecks at the busiest times."
